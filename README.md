# 课内 · 复习知识库

公开阅读入口：https://geezer565.github.io/course-review/

只收录五门课程：传感器与检测技术、计算机控制技术、反馈控制工程基础、微处理器系统、电力电子技术。

## 阅读与修改

从首页进入科目，再选择章节。每章按 1.1、1.2 等主题小节整理，同一问题的概念、公式条件与解题方法合并讲解，不再按课件页数拆分。计算机控制技术的五章已将公式、推导、例题和裁剪图示直接嵌入正文，图示可点击放大；其他科目的相关资料仍可在小节末尾展开。未提供资料的课程会显示「待补充」。

在笔记页点「修改笔记」，登录有写入权限的 GitHub 账号后修改并保存。网站由 main 分支发布；等待 GitHub Pages 更新后，电脑、手机和平板均可看到新内容。阅读不需要登录。

章节正文保存在同名 `.md` 文件中；`catalog.json` 管理科目及目录；`reference-*.json` 将补充资料归入主题；`media-*.json` 保存图示；`search-index.json` 是搜索目录。正文和补充资料均纳入搜索。新增科目或调整章节时需要一并更新目录；搜索目录由 `tools/reindex.py` 重建。发布仅包含当前目录引用的笔记，历史逐页笔记不再进入网站。

## 内容范围

按提供的课程资料归纳为 22 章、103 个主题小节，同时完整保留 1625 个来源单元的文字与图示供核对。不上传原 PDF、个人提交的作业、选修课及前沿智能理论探索资料。原有补充讲义中的数字和复杂公式应结合图示核对。

本地原始课件保持不变。`tools/convert.py` 仅用于从本地课程目录导入资料；网站阅读与日常修改不需要原课件。

计算机控制技术的裁图位于 `assets/control/`，`sources.json` 记录对应课件、页码和裁剪范围。公式由本地附带的 KaTeX 显示，许可文件保存在 `vendor/katex/LICENSE`。
