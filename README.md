# 课内 · 复习知识库

公开阅读入口：https://geezer565.github.io/course-review/

只收录五门课程：传感器与检测技术、计算机控制技术、反馈控制工程基础、微处理器系统、电力电子技术。

## 阅读与修改

从首页进入科目，再选择章节。搜索覆盖已有课程正文。公式、电路图及扫描内容在每个单元的「图示与公式」中保留，点击图示可以放大。未提供资料的课程会显示「待补充」。

在笔记页点「修改笔记」，登录有写入权限的 GitHub 账号后修改并保存。网站由 main 分支发布；等待 GitHub Pages 更新后，电脑、手机和平板均可看到新内容。阅读不需要登录。

章节正文保存在同名 `.md` 文件中；`catalog.json` 管理科目及目录；`media-*.json` 保存图示；`search-index.json` 是搜索目录。新增科目或调整章节时需要一并更新目录；正文搜索目录由 `tools/reindex.py` 重建。

## 内容范围

按提供的课程资料全文提取整理，并保留图示供核对。不上传原 PDF、个人提交的作业、选修课及前沿智能理论探索资料。资料中的原有观点和结论不代表额外核验；图片中的内容需要通过图示阅读。

本地原始课件保持不变。`tools/convert.py` 仅用于从本地课程目录导入资料；网站阅读与日常修改不需要原课件。
